`Timeline::send_file` gained an optional `thumbnail_source` parameter, so a
thumbnail can now be attached to `m.file` events. Previously only `send_image`
and `send_video` were able to send thumbnails, which meant clients could not
attach a preview they had rendered themselves for other file types — for
example the first page of a PDF.

As with the other attachment senders, the thumbnail is only sent when both
`thumbnail_source` and `file_info.thumbnail_info` are provided; supplying only
one of them is ignored. The parameter is optional and defaults to `None`, so
existing callers are unaffected.
